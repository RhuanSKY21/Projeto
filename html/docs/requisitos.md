Requisitos funcionais (RF)

RF01: O sistema deve permitir que usuário se cadastre com nome, matrícula, e-mail e senha. Prioridade: alta
RF02: O sistema deve permitir que o usuário adicione produtos ao carrinho. Prioridade: alta
RF03: O sistema deve permitir que a Livraria altere o status do pedido. Prioridade: alta
RF04: O sistema deve mostrar o histórico de pedidos do usuário. Prioridade: media
RF05: O sistema deve permitir utilizar cupons. Prioridade: media
